# Computer Networks & Security Laboratory (ENCS4130)

This repository contains a collection of high-level network engineering experiments conducted at Birzeit University. The projects focus on designing, configuring, and securing complex network topologies.

## Key Projects & Experiments

### 1. Border Gateway Protocol (BGP) & Path Vector Routing
* **Goal:** Configure multi-AS topologies and analyze EGP/IGP redistribution.
* **Key Tasks:** Established BGP peering, monitored state transitions (Idle to Established), and used packet sniffers to analyze OPEN, UPDATE, and KEEPALIVE messages.
* **Tools:** Cisco Packet Tracer, OSPF, BGP.

### 2. Cisco ASA Firewall Configuration
* **Goal:** Secure an enterprise network using a hardware firewall simulation.
* **Key Tasks:** * Implemented **Security Zones** (Inside, Outside, DMZ).
    * Configured **Static and Dynamic NAT/PAT** for secure internet access.
    * Applied **Access Control Lists (ACLs)** to regulate traffic flow to the DMZ.
    * Resolved DHCP and DNS propagation issues within a simulated environment.

## Skills Demonstrated
* **Routing Protocols:** BGP, OSPF, Static Routing.
* **Security:** ASA Firewall, NAT/PAT, ACLs, Zone-based Security.
* **Analysis:** Troubleshooting connectivity, Route Redistribution, Packet Analysis.

## Repository Structure
Each folder contains the `.pkt` (Packet Tracer) file and a comprehensive **Technical Report (PDF)** detailing the abstract, methodology, configuration commands, and results.
